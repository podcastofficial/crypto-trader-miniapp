FAQ
How do I play?

Pick a number, colour, or Big/Small option before betting closes, then confirm your points stake.

When do I win?

Winning bets settle automatically after the server publishes the result.

How are payouts calculated?

100 points on Red/Green can return 200 points, a number can return 900 points, and Violet can return 450 points if the result matches. A Red bet pays 0.5x when the result is 0, and a Green bet pays 0.5x when the result is 5.

Can I cancel a bet?

Bets cannot be cancelled after confirmation.

Minimum withdrawal?

500 points (5 USDT). A 10% fee applies.

Game Rules & Payouts

1. Select a number, colour, or Big/Small before betting closes.
2. Enter your stake and confirm the bet.
3. The server publishes the round result after the timer ends.
4. Winning bets are credited automatically; predictions are not guaranteed.

100 points examples
🔴/🟢 Red or Green: 100 × 2 = 200 points
🔢 Number 0–9: 100 × 9 = 900 points
🟣 Violet: 100 × 4.5 = 450 points
📊 Big/Small: 100 × 2 = 200 points
🔴 Red when the result is 0 / 🟢 Green when the result is 5: 100 × 0.5 = 50 points

Potential payout is shown before confirmation. A prediction is only an informational estimate, never a guaranteed result.
